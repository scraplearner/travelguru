# travelguru

Spatial Multi-Modal Journey Planner and Transit Intelligence Platform built with React, Vite, and modern GIS cartographic aesthetics.

## Features
- Multi-modal routing across Flights, Rail, Buses, and Road
- Real-time feasibility scoring and zero-buffer delay checks
- Pre-filled carrier redirection (IRCTC, IndiGo, Air India, Zingbus, etc.)
- User authentication and guest traveler instant access
- Interactive spatial GIS map visualization

## Getting Started
```bash
npm install
npm run dev
```
